前置检查：原仓库在 main，origin 为 DonarFang/SP500-tracker。允许原工作区有既存修改和未跟踪研究文件；记录原 HEAD/status/diff，不 stash、不清理、不覆盖、不快进原本地 main。只 fetch 远端并注册同仓库的隔离 worktree。隔离位置为本次 RESULTS/candidate，保留供追溯，不纳入结果 ZIP。相关源码 SHA256 必须等于制作包时读取的源码；源码变化则停止，不猜测修改位置。需要已有 git push 认证和本地 git 作者配置。结束后核对原 HEAD/status/diff 未变。原工作区不会显示干净，也不要求其 HEAD 等于新的远端 main；这些发布验收只针对隔离 worktree。
